Como usar

Blocos, rampas, lombadas, acessosArraste no mapa para desenhar um retângulo (ou só clique para criar um tamanho padrão). Shift = quadrado.
RedimensionarArraste as bolinhas nas bordas e cantos do item selecionado.
GirarBolinha acima do item (Shift = passos de 15°).
MoverFerramenta Selecionar (V) e arraste o item.
Via de veículosArraste ao longo da rua para marcar um trecho (gire para ruas inclinadas). Em Tipo escolha via, pátio, estacionamento ou cruzamento.
Ponto de interesseClique no mapa; a ponta do pin é a posição.
CaminhoClique para soltar uma bolinha · clique nela para ativar (fica maior) · clique em outro lugar ou em outra bolinha para ligar · duplo clique num trecho cria uma bolinha nele · Esc solta.
